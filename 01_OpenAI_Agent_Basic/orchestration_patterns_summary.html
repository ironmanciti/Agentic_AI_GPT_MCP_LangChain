멀티 에이전트 오케스트레이션 — 4가지 패턴 요약

LLM이 아니라 코드가 흐름을 제어하는 워크플로우 패턴

의존성이 있으면 순차, 없으면 병렬, 분기가 필요하면 분류 + 라우팅 — 실전은 이들을 결합

① 순차 체이닝Sequential Chaining

  • 핵심Runner.run(next, prev.final_output) + trace()로 묶음
  • 사용 시점각 단계가 앞 단계 결과에 의존할 때 (초안 → 편집 → 번역)

② 병렬 실행Parallelization

  • 핵심await asyncio.gather(*[Runner.run(a, text) ...])
  • 사용 시점서로 독립적인 작업 → 전체 대기 시간 ≈ 가장 느린 1개

③ 분류 + 라우팅Classification + Routing

  • 핵심output_type=RequestClassification → 코드가 agent_map으로 선택
  • 사용 시점Handoffs와 달리 결정적(deterministic) 분기가 필요할 때

④ 병렬 분석 + 순차 종합Combined

  • 핵심Step 1 asyncio.gather → Step 2 결과 결합 후 Runner.run(report, ...)
  • 사용 시점실전 워크플로우 — 여러 패턴을 조합해 구성
